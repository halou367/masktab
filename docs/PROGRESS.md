## 已知问题

1. **共享扩展数据版本号多加**：实例没改动就关闭，主副本版本号仍 +1、多一个备份。原因是 LevelDB 文件一打开就变。要在 `internal/extlib` 的 `Push` 里改进变化检测。
2. **“mihomo 起不来时是否切断”没测准**：杀掉 mihomo 后它 1 秒就自动重启了，页面照常打开。需要让 mihomo 保持起不来再测一次，确认页面打不开而不是直连。
3. （已处理）首次下载没有界面：现在用系统浏览器打开进度页，完整安装包则不需要下载，见 decisions D-1、D-2。
   下载源是 GitHub，可以在设置里填镜像前缀（`mirror`），但设置界面要等内核下载完才打得开——所以还需要一个不依赖内核的进度 / 设置入口，
   或者支持手动把内核解压到 `data/kernel/` 下（现在已经支持：放进去就会被找到）。
4. （已处理）每次启动第一个标签页上的提示条“不受支持的命令行标记：--host-resolver-rules=…”：参数保留（防 DNS 泄漏），
   加 `--test-type` 让内核不出这条提示，见 decisions U-3。新标签页底部还有一条内核加的署名栏，暂时去不掉。
5. （已处理）新标签页接管提示：改用 `--custom-ntp`，不再弹窗，见 decisions U-1。同时发现并停止了对“受保护偏好”的写入，见 U-2。
6. `subscriptions[].template.basePath` 在接口返回里曾经是空的，生成的路径是对的，没有再查。
7. `internal/core` 和 `internal/probe` 没有单元测试。

### 2026-11-14 修：两步登录记不住 / 不自动填（用户在 arena.ai 反馈）
- 原因：第二步页面只有密码框、找不到邮箱框，保存时用户名为空；第一步自动填后 `filledOnce` 挡住了第二步；页面变动观察 60 秒 / 400 次后就停，单页应用退出后回到登录页不再检查；点按钮后网页立刻清空表单时读不到值。
- 改法：第一步提交时把用户名暂存到后台（chrome.storage.session，按标签页 + 主域名，10 分钟）；第二步按暂存用户名配对保存、挑对应账号填；每个输入框各自只填一次；观察不再停止（最多每 400 毫秒检查一次）；在 pointerdown 时同步读值；查询进入开放影子 DOM；只认提交类按钮。
- 验证：沙箱模拟单页两步与多页两步登录，记住、退出后第一步填邮箱、第二步填密码均正确。未在真实 arena.ai 上验证（沙箱访问不到）。
